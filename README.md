## The toolbox

| If you want to… | Try this |
| :--- | :--- |
| **Make your terminal yours** | **[Terminal Experience Studio](https://github.com/AbduLz0/fun-cli)** — themes, prompts, picture-to-ASCII, and a companion that roasts your typos. GTK4 + Libadwaita, with backups and undo. [See it in action ↗](https://abdulz0.github.io/fun-cli/) |

## What I work with

**Under the hood:** FFmpeg · LibreOffice · BlueZ · evdev · Nmap · Ollama

## The details I care about

- **A way back.** Terminal Experience Studio has backups and undo; Hermes Local backs up existing configuration.
- **Local where it counts.** Converto processes files offline. ReconDeck keeps scan history on your machine. Hermes Local runs its model through Ollama.
- **Useful, honest feedback.** Missing controller data stays unavailable. Project READMEs explain dependencies, unsupported features and testing limits.
- **A little personality.** Practical software can still have a terminal companion that laughs at `gti status`.
